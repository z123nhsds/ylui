# YLUI 应用开发指南

## 概述

YLUI 是一个纯前端的桌面框架，提供了类似 Windows 操作系统的用户界面。本指南将帮助您快速上手 YLUI 应用开发。

## 快速开始

### 1. 环境准备

确保您已经安装了 Node.js 和 npm。

```bash
# 安装依赖
npm ci
# 启动开发服务器
npm start
```

然后访问 http://localhost:8080 即可查看效果。

### 2. 创建第一个应用

在 `res/apps/` 目录下创建一个新的应用目录，例如 `myapp/`，包含以下文件：

#### index.js (应用逻辑)

```javascript
YLApp.onReady(function() {
  log('应用已初始化！');
  
  // 监听来自其他应用的事件
  YLApp.onEvent(function(message) {
    log('收到事件: ' + JSON.stringify(message));
  });
});

function log(msg) {
  var output = document.getElementById('output');
  var time = new Date().toLocaleTimeString();
  output.innerHTML += '<p><strong>[' + time + ']</strong> ' + msg + '</p>';
}

function showMessage() {
  YL.msg('Hello YLUI!', '这是一个来自我的应用的消息。');
  log('已显示消息');
}

function sendEvent() {
  YLApp.emit('custom-event', { 
    data: 'Hello from my app',
    timestamp: Date.now()
  });
  log('已发送事件');
}

function openNewApp() {
  // 打开一个新的临时窗口
  YL.open({
    title: '临时窗口',
    url: 'https://ylui.yuri2.cn',
    icon: {
      type: 'fa',
      content: 'globe',
      bg: '#0078d7'
    }
  });
  log('已打开新窗口');
}
```

## 核心功能

### 1. 应用间通信（应用组织框架）

YLUI 提供了完整的应用组织框架，支持跨域 APP 通信能力：

#### 跨域广播事件

```javascript
// 向所有应用广播事件
YLApp.broadcastApp('workspace:updated', { key: 'value' });

// 向指定应用发送事件
YLApp.framework.send('yl-system', 'workspace:reload', { scope: 'dashboard' });
```

#### 跨域请求-响应模式

```javascript
// 注册请求处理器（在被调用方）
YLApp.framework.handle('workspace:get', function(payload) {
  return { appId: YLApp.id, data: payload, timestamp: Date.now() };
});

// 发起跨域请求（在调用方）
YLApp.requestApp('yl-system', 'workspace:get', { scope: 'dashboard' }, function(err, result) {
  if (!err) {
    console.log('收到数据:', result);
  }
});
```

#### 事件监听

```javascript
// 监听特定事件
YLApp.framework.on('workspace:updated', function(payload, context) {
  console.log('源应用:', context.sourceAppId);
  console.log('数据:', payload);
});

// 取消监听
YLApp.framework.off('workspace:updated', handler);

// 传统方式 - 监听所有消息
YLApp.onEvent(function(message) {
  if (message.event === 'custom-event') {
    handleCustomEvent(message.data);
  }
});
```

### 2. 调用 YLUI API

```javascript
// 显示通知
YL.msg('标题', '内容');

// 打开应用
YL.open('app-id');

// 设置应用徽章
YLApp.eval('setAppBadge', 5);

// 获取配置
YLApp.eval('getConfigs', null, function(configs) {
  console.log(configs);
});
```

### 3. 数据存储与后台对接

#### 配置后台存取接口

在 `configs.js` 中配置数据存储模式：

```javascript
dataStorage: {
  mode: 'remote',     // 'localStorage' | 'remote' | 'hybrid'
  remote: {
    loadUrl: '/api/data/load',
    saveUrl: '/api/data/save',
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    timeout: 30000,
    autoSave: true,
    autoSaveInterval: 30000
  },
  hybrid: {
    preferLocal: true,
    syncInterval: 60000
  }
}
```

#### 通过框架 Store 与后台对接

```javascript
// 自动配置后台存取接口
var store = YLApp.createStore({
  namespace: 'my-app',
  state: { items: [], page: 1 }
});

// 保存到后台
store.save(function(err) {
  if (!err) console.log('已同步到后台');
});

// 从后台加载
store.load(function(err, state) {
  if (!err) console.log('从后台恢复:', state);
});
```

#### 传统方式

```javascript
// 使用 localStorage
localStorage.setItem('mykey', 'myvalue');
var value = localStorage.getItem('mykey');

// 远程存储 - 自动同步
if (YL.static.dataStorage && YL.static.dataStorage.mode !== 'localStorage') {
  YL.loadRemoteData(function(err, data) {
    if (!err) YL.init(data);
  });
  
  var saveData = YL.export();
  YL.saveRemoteData(saveData, function(err) {
    if (!err) console.log('保存成功');
  });
}
```

### 4. 使用 Vue.js

YLUI 内置支持 Vue.js，并提供了响应式 Store 引擎：

```javascript
YLApp.onReady(function() {
  new Vue({
    el: '#app',
    data: {
      message: 'Hello Vue!'
    },
    methods: {
      updateMessage: function() {
        this.message = 'Updated!';
        YL.msg('通知', '消息已更新');
      }
    }
  });
});
```

利用 Vue.js 响应式特性与框架 Store 联动：

```javascript
var store = YLApp.createStore({
  namespace: 'my-app',
  state: { todos: [], filter: 'all' }
});

new Vue({
  el: '#app',
  data: {
    storeState: store.state  // 直接绑定响应式状态
  },
  computed: {
    filteredTodos: function() {
      return this.storeState.todos.filter(function(t) {
        return this.storeState.filter === 'all' || t.status === this.storeState.filter;
      }.bind(this));
    }
  }
});
```

## 数据序列化

YLUI 应用组织框架内置了基于 Vue.js 的数据序列化引擎，支持 JSON 和 XML 格式：

```javascript
// JSON 序列化
var json = YLApp.serialize({ foo: 'bar', nested: { value: 1 } }, 'json');

// XML 序列化
var xml = YLApp.serialize({ foo: 'bar', nested: { value: 1 } }, 'xml');

// 反序列化
var data = YLApp.deserialize(json, 'json');

// 导出完整数据（兼容旧版 API）
var fullData = YL.export();
console.log('序列化数据:', JSON.stringify(fullData));

// 导入数据
YL.import(fullData);
```

### Vue 响应式 Store

基于 Vue.js 的可观察状态管理：

```javascript
var store = YLApp.createStore({
  namespace: 'ylui-workspace-demo',
  state: { filters: [], widgets: [], theme: 'light' }
});

// 读取响应式状态
console.log(store.state.filters);

// 序列化当前状态
var snapshot = store.serialize('json');

// 从序列化数据恢复
store.deserialize(snapshot, 'json');

// 替换整个状态
store.replace({ filters: ['new'], widgets: [], theme: 'dark' });

// 保存到远程后台
store.save({ savedAt: Date.now() }, function(err) {
  if (!err) console.log('保存成功');
});

// 从远程后台加载
store.load(function(err, state, meta) {
  if (!err) console.log('加载成功', state);
});
```

## 常见问题

### Q: 如何调试应用？

A: 在 `configs.js` 中设置 `debug: true` 可以看到更多调试信息。

### Q: 如何让应用自启动？

A: 在应用配置中设置 `autoRun` 的值为大于 0 的数字，数值越小优先级越高。

### Q: 如何配置远程数据存储？

A: 在 `configs.js` 的 `dataStorage` 配置项中设置：

```javascript
dataStorage: {
  mode: 'remote',
  remote: {
    loadUrl: '/api/data/load',
    saveUrl: '/api/data/save',
    autoSave: true,
    autoSaveInterval: 30000
  }
}
```

也可通过应用组织框架的 Store API 直接与后台对接。

### Q: 如何实现跨域应用通信？

A: 使用 YLApp 框架 API：

```javascript
// 处理请求
YLApp.framework.handle('app:action', function(payload) {
  return { result: 'ok' };
});

// 发起请求
YLApp.requestApp('target-app-id', 'app:action', {}, function(err, result) {
  console.log(result);
});
```

### Q: 如何适配移动端？

A: 在 `configs.js` 中启用响应式布局：

```javascript
responsive: {
  enabled: true,
  smallScreenWidth: 768,
  mobileMenuMode: 'bottom',
  touchGestures: true
}
```

系统会自动识别设备类型（PC/平板/手机）、屏幕方向，动态调整任务栏高度、图标尺寸、磁贴尺寸和开始菜单宽度。
