# YLUI 应用开发指南

## 概述

YLUI 是一个纯前端的桌面框架，提供了类似 Windows 操作系统的用户界面。本指南将帮助您快速上手 YLUI 应用开发。

## 快速开始

### 1. 环境准备

确保您已经安装了 Node.js 和 npm。

```bash
# 安装依赖
npm ci
# 启动开发服务器
npm start
```

然后访问 http://localhost:8080 即可查看效果。

### 2. 创建第一个应用

在 `res/apps/` 目录下创建一个新的应用目录，例如 `myapp/`，包含以下文件：

#### index.html (应用界面)

```html
<!DOCTYPE html>
<html lang="zh-cn">
<head>
  <meta charset="UTF-8">
  <title>我的应用</title>
  <link rel="stylesheet" href="../../components/font-awesome-4.7.0/css/font-awesome.min.css">
  <script src="../../yl.app.js"></script>
  <style>
    body {
      font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
      padding: 20px;
      background-color: #f5f5f5;
    }
    .container {
      max-width: 600px;
      margin: 0 auto;

    }

      color: #333;
      margin-bottom: 20px;
    }

      background-color: #0078d7;
      color: white;

      background-color: #0063b1;

      margin-top: 20px;

    }
  </style>
</head>
<body>
  <div class="container">
    <h1><i class="fa fa-rocket"></i> 我的第一个 YLUI 应用</h1>
    
    <p>欢迎使用 YLUI 桌面框架！</p>

      <!-- 输出内容将显示在这里 -->
    </div>
  </div>
  
  <script src="index.js"></script>
</body>
</html>
```

#### index.js (应用逻辑)

```javascript
YLApp.onReady(function() {
  log('应用已初始化！');
  
  // 监听来自其他应用的事件
  YLApp.onEvent(function(message) {
    log('收到事件: ' + JSON.stringify(message));
  });
});

function log(msg) {
  var output = document.getElementById('output');
  var time = new Date().toLocaleTimeString();
  output.innerHTML += '<p><strong>[' + time + ']</strong> ' + msg + '</p>';
}

function showMessage() {
  YL.msg('Hello YLUI!', '这是一个来自我的应用的消息。');
  log('已显示消息');
}

function sendEvent() {
  YLApp.emit('custom-event', { 
    data: 'Hello from my app',
    timestamp: Date.now()
  });
  log('已发送事件');
}

function openNewApp() {
  // 打开一个新的临时窗口
  YL.open({
    title: '临时窗口',
    url: 'https://ylui.yuri2.cn',
    icon: {
      type: 'fa',
      content: 'globe',
      bg: '#0078d7'
    }
  });
  log('已打开新窗口');
}
```

### 3. 注册应用

接下来，在 `saves/basic.json` 文件中添加您的应用配置。找到 `apps` 对象，添加：

```json
"myapp": {
  "addressBar": false,
  "autoRun": 0,
  "background": false,
  "badge": 0,
  "desc": "我的第一个 YLUI 应用",
  "icon": {
    "type": "fa",
    "content": "rocket",
    "bg": "#0078d7"
  },
  "openMode": "normal",
  "plugin": false,
  "position": {
    "autoOffset": true,
    "left": true,
    "top": true,
    "x": "x*0.1",
    "y": "y*0.1"
  },
  "version": "1.0.0",
  "poweredBy": "YLUI",
  "resizable": true,
  "single": false,
  "size": {
    "height": "y*0.6",
    "width": "x*0.6"
  },
  "title": "我的应用",
  "url": "./res/apps/myapp/index.html",
  "customTile": "",
  "urlRandomToken": true
}
```

然后，在 `shortcuts` 数组中添加桌面图标：

```json
{
  "app": "myapp",
  "title": "我的应用",
  "params": {},
  "hash": ""
}
```

在 `startMenu.menu` 中添加菜单项：

```json
"myapp": {
  "app": "myapp",
  "title": "我的应用",
  "params": {},
  "hash": ""
}
```

## 核心功能

### 1. 应用间通信

YLUI 提供了强大的跨应用通信功能：

#### 发送事件

```javascript
// 向所有应用发送事件
YLApp.emit('event-name', { key: 'value' });

// 向特定窗口发送事件
YLApp.emit('event-name', { key: 'value' }, 'target-window-id');
```

#### 监听事件

```javascript
YLApp.onEvent(function(message) {
  console.log('收到事件:', message.event, message.data);
  
  if (message.event === 'custom-event') {
    // 处理自定义事件
    handleCustomEvent(message.data);
  }
});
```

### 2. 调用 YLUI API

```javascript
// 显示通知
YL.msg('标题', '内容');

// 打开应用
YL.open('app-id');

// 设置应用徽章
YLApp.eval('setAppBadge', 5);

// 获取配置
YLApp.eval('getConfigs', null, function(configs) {
  console.log(configs);
});
```

### 3. 数据存储

#### 本地存储

```javascript
// 使用 localStorage
localStorage.setItem('mykey', 'myvalue');
var value = localStorage.getItem('mykey');
```

#### 远程存储 (需配置)

如果在 `configs.js` 中配置了远程存储，数据会自动同步：

```javascript
// 数据会自动保存到远程服务器
// 也可以手动触发同步
YL.dataSync.sync(function(err) {
  if (err) {
    console.error('同步失败:', err);
  } else {
    console.log('同步成功');
  }
});
```

### 4. 使用 Vue.js

YLUI 内置支持 Vue.js，您可以使用 Vue 构建更复杂的应用：

```javascript
YLApp.onReady(function() {
  new Vue({
    el: '#app',
    data: {
      message: 'Hello Vue!'
    },
    methods: {
      updateMessage: function() {
        this.message = 'Updated!';
        YL.msg('通知', '消息已更新');
      }
    }
  });
});
```

## 数据序列化

YLUI 支持将所有数据序列化为 JSON 格式，方便与后台对接：

```javascript
// 导出数据
var data = YL.export();
console.log('序列化数据:', JSON.stringify(data));

// 导入数据
YL.import(data);
```

## 高级功能

### 1. 自定义磁贴

您可以为应用创建自定义磁贴内容：

```javascript
// 在应用中添加 customTile 配置
{
  // ... 其他配置
  "customTile": "./res/apps/myapp/tile.html"
}
```

### 2. 插件模式

```javascript
// 在应用配置中设置 plugin: true
{
  "plugin": true,
  // ...
}
```

插件应用会在后台运行，不显示在任务栏，但仍可通过其他方式访问。

### 3. 窗口参数传递

```javascript
// 打开应用时传递参数
YL.open('myapp', {
  data: { param1: 'value1', param2: 'value2' }
});

// 在目标应用中接收
YLApp.onReady(function() {
  console.log(YLApp.data); // { param1: 'value1', param2: 'value2' }
});
```

## 常见问题

### Q: 如何调试应用？

A: 在 `configs.js` 中设置 `debug: true` 可以看到更多调试信息。

### Q: 如何让应用自启动？

A: 在应用配置中设置 `autoRun` 的值为大于 0 的数字，数值越小优先级越高。

### Q: 如何配置远程数据存储？

A: 在 `configs.js` 的 `dataStorage` 配置项中设置：

```javascript
dataStorage: {
  mode: 'remote',
  remote: {
    loadUrl: '/api/data/load',
    saveUrl: '/api/data/save',
    autoSave: true,
    autoSaveInterval: 30000
  }
}
```
